# Ctrl+Play

Repositório com programas, jogos e projetos desenvolvidos para a escola de programação e robótica **Ctrl+Play**.

## Sobre

A Ctrl+Play é uma escola de tecnologia voltada para crianças e adolescentes, que ensina programação, criação de jogos, aplicativos e robótica de forma prática e divertida.

Este repositório reúne os projetos feitos durante o trabalho/estudos relacionados à empresa.
